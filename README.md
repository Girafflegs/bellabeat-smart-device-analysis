# Bellabeat Smart Device Usage Analysis

## Project Overview

This project was completed as part of the Google Data Analytics Professional Certificate Capstone. It analyzes Fitbit smart device usage data to identify consumer behavior patterns and develop data-informed marketing recommendations for Bellabeat.

## Analysis

The project examines daily activity patterns, activity intensity, participant data coverage, and sleep duration. Data from two Fitbit exports were combined and cleaned, including the reconstruction of 1,007 sleep sessions from minute-level records.

The analysis also considers limitations of the dataset, including its age, small participant population, and lack of demographic information.

## Key Recommendations

- Explore marketing messages encouraging movement throughout everyday routines.
- Investigate opportunities for sleep awareness messaging.
- Validate findings against Bellabeat customer data and test messaging before broader implementation.
